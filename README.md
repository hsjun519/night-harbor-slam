# 밤항구 슬램 (NIGHT HARBOR SLAM)

항구 도시 '야항'을 무대로 한 2D 프로레슬링 + 레슬러 커리어 게임입니다. 브라우저에서 바로 실행됩니다.
그래픽(픽셀 렌더러·한글 픽셀 폰트), 사운드(전부 WebAudio 합성), 캐릭터, 장소, 대사는 모두 이 저장소에서 새로 만든 것이며 외부 이미지·음원·폰트 파일을 쓰지 않습니다. 장르 문법(타격으로 기절 게이지를 깎고 → 다운 → 잡기 → 레슬링 기술)은 참고했지만 특정 게임의 그래픽·캐릭터·코드·사운드는 복제하지 않았습니다.

## 실행

- **플레이:** `dist/index.html`을 더블클릭하면 됩니다(인터넷 연결 불필요).
- **개발용 서버:** `node serve.mjs` → <http://127.0.0.1:4390/dev.html> (모듈 원본) 또는 <http://127.0.0.1:4390/> (빌드본)
- **빌드:** `node build.mjs` → `dist/index.html` 하나로 묶습니다.
- **테스트:** `node tests/sim.mjs 36` (AI 대 AI 전 모드), `node tests/scripted.mjs` (사람 입력 시나리오), `node tests/props.mjs` (의자·난입·돌진·코너 기술), `node tests/save.mjs` (저장 슬롯·예전 저장 옮기기), `node tests/ladder.mjs 18` (난이도 사다리), `npm run test:e2e` (헤드리스 크롬에서 키보드만으로 커리어 진행: 한글 입력기 Enter, 문·대화·메뉴·경기·의원·훈련·이어하기·게임 오버. 크롬 경로는 `CHROME_PATH`로 바꿀 수 있음)

## 조작

| 경기 | 동작 |
|---|---|
| A / D | 이동 (계속 누르면 달리기, **두 번 빠르게 누르고 유지하면 돌진**) |
| 돌진 중 K | 서 있는 상대에게 돌진 기술: 번개 커터(무거운 선수는 돌파 태클). 피니셔 게이지 15, 6초 대기 |
| W | 점프 · 로프 앞에서 코너 오르기 · 링 밖에서 링으로 |
| S | 방어(막 누른 순간 맞으면 패리) · 다운된 상대 핀폴 · 태그 교대 · S+방향으로 링 밖으로 |
| J | 공격 3단 연타 · 달리며 J = 돌진기 · 공중 J = 드롭킥 · 쓰러진 상대 짓밟기 |
| 코너 위 | A/D로 방향 · J: 서 있는 상대 = 미사일 드롭킥(또는 크로스바디), 누운 상대 = 다이빙, 바깥을 보면 장외 다이빙(탈락 규칙 경기는 금지) |
| 의자 | K 줍기(0.5초) · J 체어샷(맞으면 바로 짧게 기절, 휘두르면 바닥에 떨어짐, 세 번 쓰면 부서짐) · K 던지기 · 상대가 휘두를 때 K 또는 타이밍 L로 빼앗기 |
| K | 쓰러지거나 비틀거리는 상대 잡기 · 서 있는 상대 밀치기(가드 깨기) · 로프에서 튕겨 오는 상대 받아치기 |
| 잡은 뒤 K / →+K / ←+K / W+K / S+K | 방향별 레슬링 기술 (L: 뒤로 돌아 잡기, J: 무릎치기) |
| L | 회피 · 공격 직전에 누르면 반격 던지기 · 기술 시작 순간 `L!`에 맞추면 역전 |
| S + L | 긴급 탈출 (피니셔 게이지 35 소모, 18초 대기) |
| Space | 피니셔(게이지 가득) · 게이지가 덜 찼으면 도발 |
| Esc | 일시정지 (연습 모드 설정, 디버그 표시) · F3 디버그 |

| 탐험 | 동작 |
|---|---|
| A / D, W | 이동(두 번 빠르게 누르면 달리기), 점프 |
| E (또는 Enter · Space) | NPC 대화 · 물건 조사 · 문 앞에서는 문으로 이동. 대화창에서는 다음 / 선택 결정 |
| F | 문으로 이동 |
| Tab | 선수·커리어 정보 (능력치 포인트, 기술 장착, 소지품, **부상 게이지**) |
| M | 지도 · Esc 메뉴(저장, 설정, 조작법) |

키는 설정 → 키 설정에서 바꿀 수 있고, 게임패드(표준 배치)도 인식합니다.

- **선수 이름:** 선수 만들기 화면에 들어가면 이름 칸이 바로 열립니다. 한글 입력기 그대로 입력하고 Enter로 확정합니다(마지막 글자를 조합하는 중에 Enter를 눌러도 됩니다). Esc는 입력한 글자를 남긴 채 칸을 닫습니다. 이름 뒤 항목에서 Enter는 다음 항목으로 넘어갑니다.
- **목표 안내:** 탐험 화면 왼쪽 위의 `목표` 줄과 노란 화살표(▼, 화면 밖이면 ◀ ▶)가 다음에 갈 문이나 사람을 가리킵니다. 처음엔 사장실의 구만석 사장, 계약 뒤엔 경기장 대기실, 부상이 위험하면 항구의원입니다.

## 전투 시스템

- **HP / STUN**: 공격마다 체력 피해와 기절 피해가 따로 정해져 있습니다. 주먹은 STUN을, 레슬링 기술은 HP를 많이 깎습니다. STUN은 1.8초 동안 맞지 않으면 회복됩니다.
- **다운**: STUN이 0이 되면 다운. 다운 시간은 1회 2초 → 3 → 4 → 5 → 최대 6초 (`src/data/balance.js`의 `downTimes`). 일어난 직후에는 짧은 보호 시간이 있습니다.
- **잡기와 기술**: 다운·비틀거림 상태의 상대를 K로 잡고, 방향+K로 기술을 고릅니다. 잡기에는 제한 시간이 있고, 잡힌 쪽은 연타로 벗어나거나 기술 시작 순간 L로 역전할 수 있습니다. 들어 올리는 기술은 상대가 무거우면 체력을 깎아 놔야 들 수 있습니다.
- **연속 기술**: 기술을 맞고 쓰러진 상대를 다시 잡아 한 번의 다운에 최대 3개까지 이어 걸 수 있습니다. 이어 걸수록 피해가 줄고(기술마다 ×0.82), 세 번째 뒤에는 상대가 일어날 때까지 잡을 수 없습니다.
- **기술 26종 + 피니셔 14종**: 바디 슬램, 수플렉스, 저먼 수플렉스, 파일드라이버, 파워밤, 초크슬램, DDT, 자이언트 스윙, 아이리시 휩, 링아웃 던지기 외. 모든 기술은 `src/data/moves.js`의 데이터(피해, 들기 조건, 2인 동작 타임라인, 이벤트, 카메라 효과)입니다.
- **연타 억제**: 콤보가 길어질수록 체력 피해가 줄고, 같은 공격을 반복하면 효과와 관중 반응이 떨어지며, 헛친 큰 공격은 회복이 깁니다.
- **링**: 로프 반동, 코너 다이빙, 에이프런, 링 밖 카운트(싱글), 톱로프 너머 탈락(럼블·배틀로얄), 관중·심판·전광판 반응.
- **AI**: 반응 지연을 둔 관찰(입력을 미리 읽지 않음), 상황별 목표 선택, 헛친 틈 응징, 밀치기 끊기, 로프로 끌고 가 던지기. 쉬움·보통·어려움·전문가는 반응 속도, 판단 정확도, 행동 다양성으로 구분됩니다.

모드: 싱글, 핀폴, 태그팀(2대2, 자기 코너에서 S로 교대), 배틀로얄, 로얄럼블(일정 시간마다 입장), 길거리 승부, 연습 모드(상대 행동·체력·게이지 설정).

## 커리어

세이브 슬롯은 3칸입니다(localStorage `nhs.save1~3`, 아침 저장 지점은 각 `.chk`). 타이틀의 '새 커리어 (슬롯 고르기)'는 빈 슬롯에서 시작하고, 찬 슬롯은 덮어쓰기·지우기 전에 묻습니다. '커리어 이어하기'는 마지막으로 한 슬롯을 엽니다. 2026-11-26 이전 빌드의 시간대별 저장(`nhs.career0/1/2`)은 처음 불러올 때 슬롯 1로 옮깁니다.

로비에서 시작해 사장실(경기 제안·계약), 훈련장(벤치프레스 타이밍, 줄넘기 리듬, 미트 순서 기억, 목 브릿지 균형, 호흡), 경기장 대기실(계약·자유·연습 경기), 부둣길(항구의원, 돛대 상회, 순덕 포차, 광장, 하역장 아르바이트, 철썩 짐, 등대 돔)을 직접 걸어 다닙니다. 시즌은 28일, 하루는 오전·오후·저녁 세 칸이며 14일 만선 럼블, 21일 태그 대전, 1위+명성 55면 타이틀전이 열립니다. 계약 경기는 날짜 안에 아무 때나 치르면 되고, 서도현과의 라이벌전, 철썩 짐 도장 깨기도 있습니다.

### 이벤트와 성장

- **기초 훈련(튜토리얼):** 새 선수를 만들면 백 관장의 16단계 훈련(연계 콤보·조르기 걸기/풀기·링 밖 나가기 포함)을 받을지 묻는다. 타이틀 메뉴와 훈련장 관장에게서도 받을 수 있다. Esc로 단계·전체 건너뛰기.
- **경기 전:** 대기실에서 다음 상대가 다가와 말을 걸고, 링 위에서 기싸움 대답(도발·정중·침묵)에 따라 게이지와 관중 열기가 오른다.
- **난입:** 사장이 의자를 던지거나(피하기·막기·받기), 상대 코치가 심판을 붙잡고 의자를 넣어 준다.
- **로비 습격:** 3일째부터 부둣가 악동단이 가끔 로비에 들이닥친다. 싸우면 로비가 그대로 경기장(1:2, 한 명씩 덤빈다). 레벨과 이긴 횟수에 따라 의자를 들고 오고, 행동대장 꽁치가 늦게 난입한다. 지면 지갑을 털린다(상한 있음).
- **리벤지:** 이긴 상대가 며칠 뒤 로비에서 기다렸다가 로비 아래 지하 격투장으로 부른다(의자가 굴러다닌다).
- **기술 배우기:** 관장 수업, 철썩 짐(도장 깨기에서 이기면 확실히 한 가지), 돛대 상회 '기술의 서' 탭, 떠돌이 상인의 희귀 기술서, 처음 이긴 상대가 가르쳐 주는 기술, 골목 영감의 레슨(매일 돕다 보면 골목 끝 도장으로 초대, 마지막에 피니셔 '검은 파도'), 주간 파이널(매주 2·4·6일 랭킹 상위 선수와 보너스 경기, 이기면 기술 전수). Tab → 기술에서 받아치기·반격 칸과 피니셔(F)도 바꾼다.
- **BLACK ROPE:** 이름이 알려지면 라이벌 패거리 5인이 로비에 나타난다. 리그에 들어와 함께 성장하고, 가끔 로비를 경기장으로 만들거나(LOBBY BRAWL) 공식 경기에 난입한다. 지면 로비가 부서져 훈련장이 잠기고, 김 반장과 정리하면 다시 연다.
- **기술 숙련도:** 경력 경기에서 맞힌 기술마다 경험치가 쌓여 레벨당 피해 +3%(MAX +15%). MAX가 되면 불도그 → 러닝 불도그, 수플렉스 → F5, 바디 슬램 → 파워 슬램, 저먼 → 드래곤 수플렉스로 진화한다.
- **의자 위 슬램:** 바닥에 놓인 의자 위로 내리꽂으면 의자가 부서지며 그 기술 피해 2배(피니셔 1.5배).
- **선항 레슬링:** 첫 벨트를 딴 뒤 바다 건너 단체가 항구를 침공한다(정확히 3일 뒤 흰상아, 2차 침공은 서도현과 태그, 3차는 선장 고동 보스전). 등대 돔이 부서진 동안 타이틀전은 지하 격투장에서 열리고, 재건이 끝나면 돔으로 돌아간다. 이야기 장면은 Esc를 길게 눌러 건너뛸 수 있다.
- **가게:** 떠돌이 상인(며칠마다, 황금 너클·강철 보호대 등 다음 경기 버프), 항구 대세일 날(소모품·치료 30%), 자판기(하루 3잔).
- 지시서 전체에 대한 진행 상황은 [docs/ROADMAP.md](docs/ROADMAP.md)에 있다.

### 부상 게이지

- 경기에서 **받은 피해만큼** 조금씩 쌓입니다(체력 한 칸을 다 잃으면 약 13%, KO·피니셔를 맞으면 조금 더). 연습 경기는 쌓이지 않습니다.
- **링 밖에서만** 보입니다: 탐험 화면 상단, Tab 정보, 의원, 경기 후 결과 창. 경기 중 HUD에는 표시하지 않습니다.
- 55% 이상 주의, 80% 이상 위험(경기 전에 확인 창). **100%가 되면 게임 오버**(마지막 아침 저장 지점부터 다시 하기 가능).
- 쉬거나 자도 낫지 않습니다. **항구의원 치료**(응급·정밀·입원) 또는 **상점에서 산 붕대**로만 돈을 내고 줄일 수 있습니다. 돈이 모자라면 부상 없이 하역장 아르바이트로 벌 수 있습니다.

## 검증 범위와 한계

- 확인함: AI 대 AI 전 모드 경기 완주(오류·NaN·상태표 위반 0), 사람 입력 시나리오 80개, 헤드리스 크롬에서 키보드 입력만으로 커리어 한 바퀴(이름 입력 → 로비 → 사장실 → 계약 → 메뉴 → 경기 → 결과 → 의원 → 훈련 → 이어하기 → 게임 오버 후 다시 하기), 한글 입력기의 두 가지 Enter 순서(조합 중 Process/229, 조합 Enter 뒤 일반 Enter)를 흉내 낸 이름 확정, 저장 칸 옮기기, 단일 파일 빌드, 1280×720 캡처, 헤드리스 크롬 60fps.
- 확인 못 함: 사람이 오래 직접 플레이한 손맛과 밸런스, 실제 운영체제 한글 입력기로 친 이름(테스트는 크롬 개발자 도구의 입력기 흉내), 실제 게임패드, 저사양 PC 프레임, 사운드의 실제 청취 품질.
