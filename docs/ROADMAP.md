# 개발 로드맵 — 「프로레슬링 RPG 대규모 개선 및 콘텐츠 확장 개발 지시서」 대응

지시서(2026-11-26 전달)는 1~5단계로 나눠 진행한다. 이 문서는 지시서 항목마다 지금 상태를 적는다.
표시: **완료**(플레이·테스트로 확인), **일부**(핵심은 있으나 지시서 범위의 일부만), **예정**(아직 없음).

기본 원칙은 지시서 그대로다: 레슬링 게임으로서 재미가 먼저, 기존 기능은 유지, 철학은 기존 시스템(뉴스·대사·해설·엔딩 하이라이트)으로 전한다.

## 1단계 — 핵심 전투

| 지시서 항목 | 상태 | 지금 구현 |
|---|---|---|
| HP / STUN 유지, 다운 시간 증가와 상한 | 완료 | 다운 2→6초 상한, 기상 보호. 체력 전체 1.5배(`hpScale`) |
| 초반 다운에서 기술 연타 억제 | 완료 | 다운 횟수별 연속 기술 1→2→2→3개, 짧은 기술 후 다운(`moveChainByDown`) |
| STAMINA | 예정 | 2단계 시작 전에 넣는다. 공격·회피·돌진 소모, 휴식 회복, 바닥 시 행동 제한 |
| SPECIAL(특수 자원) | 일부 | 피니셔 게이지가 SPECIAL 역할. 돌진 기술 15 소모, 피니셔 100 |
| 기절 이외 발동 조건 | 일부 | 돌진 기술(서 있는 상대: 번개 커터·돌파 태클), 코너 기술(서 있는/누운/일어나는 상대), 로프 반동 공격, 받아치기 기술. 로프 목표(619형)·코너 그래플은 예정 |
| 반전·카운터 | 일부 | 기술 역전(L!), 회피 반격 던지기, 패리, 긴급 탈출, 의자 받아치기, 돌진·코너 기술 패리. 경기당 사용 제한은 예정 |
| 반복 효율 보정 | 완료 | 최근 6회 기록 기준 감소(번갈아 써도 초기화 안 됨), 관중 반응 감소 |
| 상황 기반 기술 HUD | 일부 | 하단 상황 안내(돌진·코너·의자·잡기·핀폴, 못 쓰는 이유 표시). 아이콘 슬롯형 HUD는 예정 |
| 기술 장착·습득 | 일부 | 잡기 10칸 + 코너 2칸. 습득: 관장 수업, 철썩 짐, 돛대 상회 '기술의 서', 떠돌이 상인 희귀서, 처음 이긴 상대가 가르쳐 줌 |
| 기술 데이터 구조 | 일부 | `MOVES`/`ATTACKS` 데이터 기반. 지시서 38절 필드(분류·요구 상태·쿨다운·경기 규칙) 정리는 예정 |
| 상태 계층 분리 | 예정 | 지금은 FSM 하나 + 보조 플래그(dash·prop·perch 방향) |
| AI 대응 | 일부 | AI가 돌진 기술·의자·장외 다이빙·의자 받아치기를 같은 규칙으로 쓴다 |

## 2단계 — 경기장 확장

| 지시서 항목 | 상태 | 지금 구현 |
|---|---|---|
| 링 안·밖 이동, 로프·코너 | 완료 | 코너 위 방향 전환, 링 밖으로 장외 다이빙(탈락 규칙 경기에서는 금지) |
| 소품 | 일부 | 접이식 의자: 줍기 0.5초, 휘두르면 떨어짐, 3번이면 부서짐, 던지기·빼앗기·받아치기, 의자 기절은 짧고 다운 횟수에 안 쌓임. 테이블·사다리·방망이 예정 |
| 반칙 판정 | 예정 | 지금은 의자가 모든 경기에서 허용(심판은 한눈팔기만) |
| 새 경기 종류 | 일부 | 로비 난투(1:2 핸디캡), 지하 리벤지. No DQ·FCA·하드코어·테이블·래더·케이지·아이언맨·백스테이지 예정 |
| 관중 호응도 | 일부 | 열기 수치가 피니셔 충전에 반영, 도발·다양한 기술에 반응. 보상·명성·뉴스 연동 예정 |

## 3단계 — 월드와 라이벌

| 지시서 항목 | 상태 | 지금 구현 |
|---|---|---|
| 로비 습격 | 일부 | 부둣가 악동단(갈치·멸치)이 3일째부터 가끔 습격 → 로비가 그대로 경기장. 승리 보상·패배 시 소지금 상한 있는 손실. 지시서의 BLACK ROPE 5인 패거리·시설 복구는 예정 |
| 공식 경기 난입 | 일부 | 사장의 의자 투척, 상대 코치 난입(심판 한눈팔기). 라이벌 패거리 난입·무효 처리 예정 |
| 리벤지 | 완료 | 진 상대가 며칠 뒤 로비에서 기다렸다가 지하 격투장으로 부른다 |
| 상점 이벤트 | 완료 | 떠돌이 상인(5일 주기), 항구 대세일(소모품·치료 30%), 자판기 하루 3잔 |
| 사업가 의뢰, 노숙인(전 챔피언) | 예정 | 3단계에서 이벤트 관리자와 함께 |
| 이벤트 관리 시스템 | 예정 | 지금은 장소 진입 때 조건 검사(`townEvents`). 지시서 39절 구조로 옮긴다 |

## 4~5단계 — 커리어 스토리, 엔딩

챕터 1~6, 단체 이적, 뉴스·해설, 사장·라이벌·사업가·전/현 챔피언의 관점, 멀티 엔딩 5종, 실제 기록 기반 하이라이트, 커리어 아카이브: **모두 예정.**
경기 기록(`history`, `h2h`, `seasonLog`)은 이미 저장되므로 하이라이트와 "각본" 생성의 재료로 쓴다.

## 이번에 반영한 직접 요청 (2026-11-26)

- 코너 위에서 A/D로 방향 전환, 바깥을 보고 J면 장외 다이빙
- 코너 위 기술: 서 있는 상대 미사일 드롭킥·플라잉 크로스바디, 누운 상대 각자의 다이빙, 일어나는 상대는 착지 타이밍, 사거리 밖은 표시
- 로비·거리에서 A/D 두 번 빠르게 → 달리기, 경기장에서는 두 번 누르고 유지 → 돌진(돌진 중 K: 번개 커터·돌파 태클)
- 서 있는 상대에게 거는 기술은 마지막 순간의 방어(패리)나 회피·역전으로 받아칠 수 있다
- NPC 대사 다시 쓰기, 경기 전 상대가 대기실에서 다가와 말 걸기, 링 위 기싸움(대답에 따라 게이지·열기)
- 백 관장 튜토리얼 12단계(건너뛰기 가능): 새 선수 생성 직후, 타이틀, 훈련장 관장
- 부상 20% 빨리 쌓임, 붕대·치료비 20% 인하·치료량 30% 증가, 정밀 치료 30% 인하
- 의자: 크게, 접어서 머리 위로, 줍기 0.5초, 한 번 휘두르면 떨어짐, 3번이면 부서짐, 의자 기절 별도 처리, 받아쳐서 빼앗기

## 알려진 문제

- AI 난이도 차이: 2026-11-26 사다리 테스트(18판씩)에서 보통>쉬움 13/18, 어려움 대 보통 7/18, 전문가>어려움 10/18. 체력 1.5배·연속 기술 제한 뒤로 어려움과 보통의 차이가 거의 없어졌다. 스태미나를 넣을 때 AI 난이도별 판단(돌진 기술·의자·코너 사용 빈도)을 함께 조정한다.

## 다음 순서 제안

1. STAMINA 도입과 HUD(1단계 마무리), 경기당 반전 제한
2. 반칙 판정과 No DQ·하드코어 경기, 테이블 소품(2단계)
3. 이벤트 관리자 + BLACK ROPE 5인 + 사업가·노숙인 이벤트(3단계)
4. 챕터·뉴스·해설(4단계), 엔딩·하이라이트·아카이브(5단계)
