# 개발 로드맵 — 「프로레슬링 RPG 대규모 개선 및 콘텐츠 확장 개발 지시서」 대응

지시서(2026-11-26 전달)는 1~5단계로 나눠 진행한다. 이 문서는 지시서 항목마다 지금 상태를 적는다.
표시: **완료**(플레이·테스트로 확인), **일부**(핵심은 있으나 지시서 범위의 일부만), **예정**(아직 없음).

기본 원칙은 지시서 그대로다: 레슬링 게임으로서 재미가 먼저, 기존 기능은 유지, 철학은 기존 시스템(뉴스·대사·해설·엔딩 하이라이트)으로 전한다.

- 래더 매치: 링 중앙에 접힌 사다리를 K로 펼침(맞으면 다시 쓰러짐) → 양쪽에서 한 명씩 오름 → 꼭대기에서 A/D로 내려갈 쪽 선택(반대편으로 넘어가기) → 가방은 타이밍 10번(맞출수록 바늘이 빨라지고 칸이 좁아짐, 맞춘 횟수는 가방에 남아 다음 사람이 이어받음). 아래에서 K: 낮게 오른 상대 끌어내리기 또는 사다리 접기(가방에 손을 댄 사람은 매달린 채 남아 계속 타이밍 가능). 위에서 J: 같은 높이 주먹(첫 대는 흔들림, 두 번째는 추락)·아래 상대 발차기·바닥 상대 발차기·다이빙(높이만큼 강함), K: 위 상대 다리 잡아 끌어내리기. 떨어지면 오래 다운

## 이번에 반영한 직접 요청 (2026-11-27 ~ 28, 2차)

- 세이브 슬롯 3칸(새 커리어는 빈 슬롯에서, 찬 슬롯은 덮어쓰기·지우기 전에 묻는다), 긴급 탈출 비용 35 → 46, 자이언트 스윙처럼 놓은 뒤에 맞는 기술의 피해 누락 수정
- 기술 숙련도(`src/data/mastery.js`): 경력 경기에서 맞힌 잡기 기술·피니셔마다 경험치 10(한 경기 4회까지, 스파링 절반), Lv1~MAX 레벨당 피해 +3%. MAX가 되면 진화: 불도그 → 러닝 불도그, 수플렉스 → F5, 바디 슬램 → 파워 슬램(S로 바로 누르기), 저먼 → 드래곤 수플렉스. 진화 기술은 원래 칸에 장착되고 원래 기술도 남는다
- 부둣가 악동단: 처음엔 약하게(체력 72%, 쉬움, 한 명이 붙어 있으면 나머지는 차례를 기다림, 동시에 최대 2명). 레벨과 악동단을 이긴 횟수에 따라 갈치가 의자를 들고 오고 → 행동대장 '꽁치'가 늦게 난입(한 명이 쓰러지거나 60초) → 둘이 의자를 든다(`GANG`). 대역 AI '보통' 기준 승률 구 0% → 45/43/30/30%
- 기술 습득 버그: 철썩 짐 도장 깨기에서 이기면 약속대로 기술을 확실히 가르친다(전에는 60% 확률). '받아치기'(스파인버스터 등)·'반격' 기술이 기술 탭에 안 보이던 문제 → 기술 탭에 받아치기·반격 칸 추가. 습득 알림에 어느 목록(정면/뒤 잡기·받아치기·반격)인지 표시. 부상 위험일 때 레슨 대화가 사라지던 문제 수정. 기술 탭 F: 아는 피니셔 중에서 바꾸기
- 의자 위 슬램: 바닥에 놓인 의자 위로 상대를 내리꽂으면 의자가 부서지며 그 기술 피해 2배(피니셔 1.5배, `chairSlam`). 의자를 든 채 비틀거리는 상대에게 K → 의자를 등 뒤에 두고 잡기 → 뒤로 넘기는 기술로 연결
- 기초 훈련 16단계: 연계 콤보, 조르기 걸기(백브레이커 → K), 조르기 풀기(연타), 링 밖으로 나갔다 들어오기 추가. 조작법 화면에도 조르기·링 밖·의자 슬램
- 로비: 트로피 진열장과 포스터를 문에서 떼고, 문 앞에서는 문이 먼저 잡힌다. 포스터 벽은 벨트 주인 얼굴(챔피언이 되면 내 얼굴)과 랭킹 상위 3명, 진열장에 내 벨트·가방·주간 파이널 컵, 상황별 현수막(챔피언·가방·연승·시즌), 랭킹판 챔피언 이름, 챔피언이면 꼬마 팬과 기자
